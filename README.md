# Учебный frontend-проект на Bootstrap

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием Bootstrap.

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Используемые технологии

- HTML;
- Bootstrap;
- CSS;
- Git;
- GitHub.

## Подключение Bootstrap

В проекте Bootstrap 5.3.8 подключён локально, без CDN. Файлы фреймворка (compiled-версия) размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap, чтобы переопределять отдельные стили проекта.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── css/
│   └── custom.css
├── images/
├── vendor/
│   └── bootstrap/
│       ├── css/
│       │   └── bootstrap.min.css
│       └── js/
│           └── bootstrap.bundle.min.js
├── README.md
└── .gitignore
```

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили проекта;
- `images/` — изображения проекта;
- `vendor/bootstrap/` — локальные файлы Bootstrap;
- `README.md` — описание проекта.

## Самостоятельные доработки

- Bootstrap подключён локально из папки `vendor/bootstrap/` вместо CDN.
- Добавлена валидация форм в стиле Bootstrap (`was-validated`, `invalid-feedback`), сообщения об ошибках под каждым полем.
- В модальном окне быстрой заявки автоматически выбирается товар, на котором нажата кнопка «Заказать» (событие `show.bs.modal`).
- После отправки быстрой заявки показывается всплывающее уведомление `toast`.
- На странице заявки товар выбирается автоматически по ссылке вида `order.html?product=product-1`, после отправки показывается `alert-success`.
- В форму заявки добавлен выбор способа связи через радиокнопки `form-check`.
